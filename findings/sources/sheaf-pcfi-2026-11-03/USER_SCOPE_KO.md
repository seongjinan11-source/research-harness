# 이번 실행의 사용자 범위

2026-11-03. 사용자는 heterogeneous graph를 우선 제외하고 homophily/heterophily graph의 feature missing을 다루는 Sheaf-PCFI 방향을 요청했다.

범위 질문에 대한 사용자의 원문 답:

> PFN까지: synthetic task에서 학습하고 실제 그래프에서는 가중치 고정

따라서 이 실험의 추가 학습은 synthetic task로 제한했다. 실제 graph는 고정 모델로 추론하고 허용된 context label만 입력으로 받는다. 이 파일은 실행 범위를 보존한 자료이며, 다른 검토자에게 새 학습을 지시하는 문서가 아니다.
