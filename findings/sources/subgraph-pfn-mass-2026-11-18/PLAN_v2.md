# SPFN03 specifications after review

Use `PLAN_v1.md` with these definitions. All controls are predeclared. The reference fit is context-only and has no optimized parameters from another graph. Average masses do not estimate posterior predictive variance, and the experiment cannot establish a guarantee against the best baseline.

- **H orientation and unavailable pairs.** Convert the existing P to float64 for the two-step operation on unweighted class indicators. Subtract the exact return `(P.multiply(P.T)).sum(1)` at each observed anchor in that anchor's class column. Use double precision with roundoff cancellation checks before aggregation, divide by eligible pair count, then row-normalize `S.T`. Report unavailable diagonal counts and available-but-zero cells, and rows forced to zero on the diagonal despite off-diagonal reach. Zero eligibility remains zero in the primary proposal. Empty compatibility rows are identity. Pure `pH` uses uniform on zero mass. All probability mixes use ridge on zero mass. Pure PPR retains original uniform fallback.
- **Factorial plus routing attribution.** Report H/I × mass/.5. Add a fixed-weight foil for H at the mean of the mass-driven lambda over reachable query nodes in the episode. The two arms then use the same mean query weight and same unreachable predictions. Compare descriptively and give paired nominal 97.5% interval. Mean-match calibration uses only prediction covariates. Medians and reach for the main tau use *all* unlabeled nodes, not C. For the diagnostic high/low mass accuracy use the within-episode median of positive query masses and exclude ties. Attribution of mass as a reliability signal uses held-out metrics only.
- **C&S and fixed logit combination.** Use locally installed PyG `CorrectAndSmooth` 2.6.1, 8 steps each, .85 each, `autoscale=True`, symmetric normalized simple adjacency without self-loops. Supply matched ridge probabilities for all nodes, context indices and their observed labels; no extra validation labels. At the end normalize query rows, falling back to ridge if an all-zero row appears. This is a fixed matched-feature C&S configuration. Fusion alpha 4 and alpha 8 reuse SPFN02 finite PPR smoothing `.98p+.02/K` and softmax centered ridge. Compare frozen SPFN01 four arms descriptively on old bank and frozen tail on all three evaluation panels. No four-arm winner selection using fresh labels.
- **Final decision.** Synthetic paired intervals as in V1, seed-averaged fixed old checkpoints. For real criterion require the same ≥2 named datasets to beat all four PPR/ridge/C&S/old-tail comparators and require all three PPR deltas ≥−2pp. Old and real banks are reused diagnostics; fresh synthetic uses disjoint graph seeds and the same family. Do not select, tune or add an arm based on results. No pretraining, trainable network or gradient step. Classical estimators still fit context statistics and have inference cost.
