# SPFN02 결과 — 스칼라 확산과 PPR 피처 보정

기존 그룹 요약을 스칼라 확산으로 바꾸면 동일한 분류 결과를 더 빠르게 얻었다. 별도로 학습한 PPR 피처 보정은 합성 그래프의 기준을 모두 통과했으나, CiteSeer에서 PPR 대비 하락 폭이 사전 기준을 넘었다.

## A. 같은 요약의 계산 순서 변경

기존 유한 8회 PPR 확산에서 그룹의 특징 벡터를 전파하는 대신, 앵커별 스칼라 질량을 전파하고 query에서 가중 특징 모멘트를 합산했다. 그룹 편성, 질량이 0일 때의 대체값, 기존 학습 체크포인트를 모두 재사용했다. 기존 합성 96개와 실제 15개 평가 사례에서 `tail`과 `proportional` 각각 학습 seed 3개를 비교했다. 최대 확률 차이는 **3.58e−7**, 최대 pair 입력 차이는 **7.15e−7**였다. 기존 직접 구현은 저장 예측을 정확히 재현했고, 스칼라 경로에서 argmax 변경은 0건이었다. 모든 사례에서 스칼라 경로를 사용했다. 큰 그룹의 직접 확산 분기는 별도 개발 테스트로 확인했다.

| 실제 그래프 첫 draw | 기존 그룹 요약 | 스칼라 그룹 요약 | 전체 앵커 | 기존 그룹 요약 대비 가속 | 전체 앵커 대비 가속 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Cora | 41.88 ms | 11.26 ms | 20.82 ms | 3.69× | 1.81× |
| CiteSeer | 49.98 ms | 11.59 ms | 20.05 ms | 4.32× | 1.67× |
| PubMed | 126.55 ms | 31.27 ms | 33.06 ms | 4.03× | 1.03× |

시간은 CPU 한 스레드, warmup 이후 교차 측정 7회의 중앙값이다. 가속 배수는 개별 반복의 paired 비율 중앙값이다. 입력의 무작위 24차원 투영과 원본 로딩은 계측 범위 밖이다. Cora에서 확산 열 수는 446에서 56으로 감소했다. 작은 합성 6건 중 기존 그룹 요약보다 빠른 사례는 3건, 전체 앵커보다 빠른 사례는 2건이었다. PubMed의 전체 앵커 대비 차이는 작았다. 결과 파일은 지정한 버퍼 크기를 기록하며 프로세스 최대 메모리는 측정하지 않았다.

## B. PPR 분류 점수에 학습된 피처 보정 추가

class-balanced PPR을 2% 균등 확률로 평활화했다. 고정 결합 모델은 별도 합성 개발 48개 과제의 NLL로 ridge 점수 계수 4를 선택했다. 학습 보정 모델 두 개는 같은 3,745개 파라미터, 초기화, 과제 순서와 각 512회 업데이트를 사용했다. 첫 모델에는 ridge 점수, 두 번째에는 ridge 점수와 20개 관측 피처 요약을 줬다. 둘 다 피처 입력이 0인 forward를 빼서 피처를 제거하면 구조 기저를 그대로 반환한다. 합성 query 라벨은 CE 학습에만 사용했고 실제 그래프에서 가중치 업데이트는 0회였다.

| 평가 | PPR | Ridge | PPR+ridge | ridge 점수 보정 | 피처 요약 보정 | 기존 frozen tail |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 합성 96개 | 35.21 | 72.77 | 70.20 | 70.50 | **76.29** | 76.27 |
| Cora | 62.95 | 36.25 | 62.95 | 64.38 | **64.85** | 41.37 |
| CiteSeer | **42.60** | 24.06 | 38.33 | 39.27 | 40.07 | 24.90 |
| PubMed | 60.00 | 42.08 | 55.83 | 60.00 | **60.90** | 48.13 |

수치는 balanced accuracy (%). 실제 그래프는 기존 Cora·CiteSeer·전체 PubMed의 그래프별 다섯 draw를 재사용했다. Cora의 PPR와 고정 결합은 같은 bAcc를 냈지만 예측은 178건 바뀌었다. 합성 학습은 6회, 총 3,072 updates이며 seed·입력·출력 해시는 `results/b_manifest.json`과 `results/b_training.json`에 있다.

| 새 합성 평가의 사전 기준 | 차이 (%p) | Paired 97.5% CI (%p) | 결과 |
| --- | ---: | ---: | --- |
| 피처 요약 보정 − PPR+ridge, 전체 bAcc | +6.09 | [+4.17, +8.05] | 통과 |
| 피처 요약 보정 − PPR, 전체 bAcc | +41.08 | [+38.52, +43.62] | 통과 |
| 피처 요약 보정 − PPR+ridge, tail recall | +16.23 | [+13.19, +19.38] | 통과 |
| 피처 요약 보정, 정렬된 X − 셔플 X | +45.74 | [+43.29, +48.19] | 통과 |

구간은 같은 base graph 안에서 seed 결과를 평균하고 8개 층의 그래프를 5,000회 paired bootstrap한 값이다. 보조 비교에서 ridge 점수만 준 모델 대비 **+5.79%p** [+4.01, +7.68], 합성 dev bAcc로 계수 8을 고른 PPR+ridge 대비 **+4.45%p** [+2.65, +6.28]였다. 기존 frozen tail과는 전체 bAcc 차이가 +0.02%p였고 tail recall은 75.30% 대 77.14%였다. 피처 요약 보정의 합성 NLL/Brier는 0.6002/0.3116, 고정 결합은 0.8846/0.4221, frozen tail은 0.5993/0.3135였다.

실제 패널에서 PPR을 기준으로 tail recall은 Cora **+5.05%p**, CiteSeer **+1.25%p**, PubMed **+2.19%p**였다. head recall은 각각 **−2.29**, **−6.32**, **−1.67%p**였다. CiteSeer에서 PPR 오답을 고친 수는 seed별 73·99·81건, PPR 정답을 잃은 수는 96·121·109건이었다. 전체 bAcc는 고정 결합보다 세 그래프 모두 높았으나, CiteSeer는 순수 PPR보다 2.53%p 낮았다. 따라서 실제 그래프별 하락을 2%p 이내로 제한한다는 기준에 실패했다. NLL/Brier는 CiteSeer와 PubMed에서 PPR보다 낮았고 Cora에서 높았다.

## 판정

- **A 보존.** 기존 요약의 예측을 보존하는 스칼라 계산으로 재사용할 수 있다. B 피처 보정과는 별도로 계측했다.
- **B 종료.** 강한 고정 결합과 점수만 쓰는 모델을 넘은 합성 결과 및 실제 희소 클래스 recall 상승은 기록한다. 현재 RP24·합성 prior·보정 head 조합을 다시 튜닝해 실제 그래프 성과로 확장하지 않는다. CiteSeer의 하락이 head recall에서 나타난 것은 확인했으며, 그 원인이 투영, prior, 피처 요약, 학습 목표 중 무엇인지는 분리하지 않았다.

합성 평가는 새 graph seed를 사용했으며 동일 생성기 계열이다. 실제 데이터는 개발 때 살펴본 그래프다. 피처가 전혀 없을 때 PPR 복귀는 확인했으며, 피처가 있는 경우의 성능 하한은 보장되지 않는다. 일반 결측 패턴에 대한 성능은 이번 실험에서 측정하지 않았다.
