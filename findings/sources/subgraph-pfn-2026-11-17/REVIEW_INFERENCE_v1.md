# SPFN01 계획 독립 검토: 수학·추론·구현

2026-11-17. **조건부 진행 권고.** 유한 restart diffusion의 질량·일차 모멘트는 그룹 합산과 정확히 교환한다. 이 사실만으로 singleton decoder 출력이나 posterior가 보존되지는 않는다. 아래에서 quota·PCA tie·안전한 readout·chunk 학습·full baseline 비용을 고정하면, 같은 예측 토큰 예산에서 scarce-anchor 보존과 head 압축의 효과를 검증할 수 있다. 이번 검토는 계획 읽기와 수식 검토만 수행했다.

1. **Diffusion 정의와 oracle을 고정한다.** 입력 무향 edge를 중복 없이 양방향으로 만들고 기존 self-loop를 제거한 뒤 정점당 loop 하나를 더한다. `P[i,j]`는 도착 row `i`가 이웃 `j`를 읽는 평균이며 isolate는 `P[i,i]=1`이다. 표준화는 문서화한 epsilon/상수열 정책으로 episode의 관측 X에서 한 번 적용한 후 `H=[X,PX,P²X]`를 만든다. 전체 X·G를 보는 것은 이 완전 관측 transductive 설정에서 허용된다. `F0=S`의 T=8 dense oracle은

   `D8 = α Σ_{k=0}^7 β^k P^k + β^8 P^8`, `α=.15, β=.85`.

   마지막 항의 계수는 `αβ^8`이 아니다. 서로 차수가 다른 무향 그래프를 fixture에 넣어 `P`와 `Pᵀ` 오류를 구분한다. 파티션의 모든 그룹 질량·모멘트를 합한 값이 동일 연산의 context 질량·모멘트와 **query별로** 같은지 확인한다. Row stochasticity가 graph 전체의 seed column sum 보존을 뜻하지는 않는다. Tiny 검사는 FP64, 실제 diffusion/mass division은 최소 FP32로 고정한다.

2. **Quota와 partition은 permutation에 대해 명시적으로 정의한다.** `n_c`는 관측 support만 사용한다. Tail quota `k_c=n_c` if `n_c≤4`, else `min(2,n_c)`이며 `B=Σk_c`. Proportional은 각 represented class에 하나를 준 뒤, `k_c<n_c`에서 `n_c/(k_c+1)` 최대인 클래스에 한 자리씩 주는 capped highest-averages 등이면 충분하다. 이 규칙 또는 하나의 bounded apportionment를 정확히 고정하고 매 episode `Σk_c=B`, `1≤k_c≤n_c`, 빈 그룹 없음, anchor 정확히 한 그룹을 assert한다. 동률은 label 정수 대신 고정 물리 node ID의 최소값 등 class-renaming 불변 기준으로 해결한다. Top은 tail의 **동일한 class별** quota와 finite `D8[q,i]` 및 안정 node-ID tie-break를 사용한다. Tail/head 둘 다 존재하는지는 생성 시 검증한다. 전체가 tail이면 압축 효과 검증에서 세 arm이 사실상 같아질 수 있다.

   한 class의 centered standardized `X_C`에서 PC1을 구하는지 `H_C`에서 구하는지 고정한다. V1의 “부호 반전은 그룹 순서만 바꾼다”는 홀수 `n_c` 또는 불균등 bucket에서 틀리다. 예를 들어 `n_c=13`을 `[7,6]`으로 쪼개면 부호 반전 시 중앙 anchor의 그룹이 바뀐다. 가장 큰 절대 loading의 지정 feature 좌표가 양수가 되도록 부호를 고정하고, 상위 두 eigenvalue가 수치적으로 같은 경우에는 사전 정의한 eigengap 기준 아래 고정 물리 ID 순서로 fallback한다. Projection 동률 및 floor/ceil bucket 경계를 함께 명시한다. Permutation 검사는 안정 ID가 각 원래 정점에 붙어 따라가도록 한다. 대칭·근동률 경우 모든 임의 label/order에 bitwise equivariance를 주장할 필요는 없다. ID는 결정적 split/tie에서만 쓰고 MLP 입력에는 넣지 않는다.

3. **Tensor 계약, zero reach, loss를 prelock에 닫는다.** `m=D8 B_g`와 `u=D8(B_g H)` 중 도달 predicate는 질량에서 얻는다. `safe_m=where(m>0,m,1)` 후 `local=where(m>0,u/safe_m,global_mean)`을 적용한다. `where(m>0,u/m,...)`만 쓰면 선택되지 않은 zero division이 gradient를 오염시킬 수 있다. Cosine은 zero norm 안정화를 고정한다. `reached`는 pair feature로 넘기고 softmax valid mask에서는 padding만 제외한다. 그렇지 않으면 해당 class에 모든 mass가0일 때 all-masked NaN이 생기고 global fallback도 무효화된다. Pooling은 `softmax_g(score+log(count))`를 class 안에서 수행한다. Top의 `n_c/k_c`는 가상 count로서 실제 singleton count·보존된 mass와 구분해 기록한다. Class 안 같은 가상 count는 softmax의 공통 offset이라 상쇄되지만 pair MLP count channel에는 여전히 영향을 준다. Top이 버려진 anchor의 모멘트를 복원하지 않으므로, tail−top은 **class quota를 맞춘 compressor 전체와 selector의 비교**이지 compression에서 하나의 요소만 분리한 결과는 아니다.

   Query train chunking은 전체 episode에서 계산한 `K_Q`와 각 class의 query 수 `n_y^Q`를 사용해 `Σ_q CE_q/(K_Q n_y^Q)`를 chunk마다 더한 뒤 optimizer를 한 번 step한다. Chunk별로 다시 class-balanced mean을 내면 목표가 바뀐다. Group chunking이 필요하면 class별 logsumexp와 weighted numerator/denominator를 유지한다. 블록별 softmax 또는 class logits 평균은 전체 softmax와 다르다. Gradient 검사의 기본 대상은 모든 arm의 pair/class head 파라미터다. PC/top/quota가 discrete fixed preprocessing이면 그 경계를 미분 가능하다고 주장하지 않는다.

4. **Strong exact implementation에 대해 비용을 비교한다.** 압축 diffusion은 개선 전 계산량이 `O(T(E+N)B(3F+1))`이다. Full/top의 singleton에서는 도달 여부와 무관하게 local/global centroid가 해당 anchor의 H다. 따라서 양쪽 모두 `N×|C|` **mass-only** diffusion과 H gather가 같은 결과를 내며, 압축 arm에서도 singleton 부분에 적용할 수 있다. Full을 `N×|C|×(3F+1)`까지 강제로 할당한 경우와 효율 주장을 비교하지 않는다. Resident grouped context guard의 단위는 `B` 대 `|C|`로 정의하고, 실제 상주 diffusion columns/peak bytes·selected tokens per query·전처리/lookup/MLP latency를 별도로 기록한다. BQ/그룹 블록 크기, dtype, 동일 warmup·synchronization, host/device transfer 및 공유 preprocessing 재사용 정책도 명시한다. 토큰 2× 감소는 end-to-end 메모리/시간 2× 감소와 동치가 아니다. Top은 예측 토큰은 B지만 exact retrieval 과정의 singleton evidence는 별도 비용이다.

**필수 최소 검증.** 차수 다른 연결성분과 isolate가 있는 작은 graph에 대해 dense polynomial 및 full singleton 합산 oracle, disconnected query/zero centroid에서 finite logits·head gradients, compressed singleton과 mass-only logits/gradient parity를 검사한다. `B=|C|` fixture에서는 top/all-singleton tail/full의 순서만 달라지는 경우도 비교한다. `n_c=1/4/5/13`, capacity saturation, PC degeneracy, equal mass와 permutation을 포함한다. 고정 arm/θ에서 query order·chunk size·query subset을 바꿔 공통 query logits과 episode loss gradient의 일치를 확인한다. Node/class rename 비교는 stable IDs와 old→new class axis를 함께 매핑한다. Real/synthetic label-aware episode drawing과 scoring은 모델 밖에서 수행하고, 모델의 allowlist는 `X,G,C,y_C,Q` 및 필요한 클래스 좌표/고정 split ID로 제한한다. Oracle/drawing에만 쓰는 full y, query truth, 클래스 population·roles는 forward/cache/group ordering에서 빠져야 한다. 같은 입력으로 query truth를 임의 치환해 logits·quota·preprocessing hash가 불변인지 검사한다.

**판정 가능 범위.** Tail−proportional은 동일 decoder/토큰 수에서 관측 support에 따른 quota 정책 효과를, tail−top은 quota를 맞춘 summary 대 선택을 검정한다. 두 contrast와 full guard는 유지한다. No-training balanced PPR은 `score_c=Σ_{g∈c}m_qg/n_c` 뒤 class normalize, 전부 zero이면 uniform으로 고정하면 비교가 재현 가능하다. Centroid baseline의 distance·확률 변환도 prelock에 고정한다. 이 검증과 결과는 유한 diffusion의 보존·압축 실효를 뒷받침할 수 있으나, posterior 보존이나 GraphPFN을 대체하는 범용 추론을 입증하지 않는다.
