# SPFN01 — bounded context for label-skewed Graph ICL

Question: under the same small prediction-token budget, does retaining each scarce labeled anchor and compressing the abundant labels' local evidence retain better tail prediction than selecting representative raw anchors or allocating token capacity by frequency? This is a local prototype, not a novelty claim, backpropagation-free pretraining, or end-to-end constant-time search.

## Model

An episode supplies undirected G, features X, observed context indices C and labels y_C, and query indices Q. Every episode's known class vocabulary is represented in C. No true unlabeled labels or class populations enter the inference interface. Tail = observed count ≤4 (not true class minority). Keep each tail anchor as a singleton, group abundant observed labels into at most two class-specific prototypes. Groups are contiguous buckets of a deterministic order based on projection onto the first within-class feature principal component (fall back to context order for degeneracy; sign reversal changes group order, no strict tie equivariance claim). Nodes without a label can carry messages but cannot become labelled anchors.

Let H=[X,PX,P²X] after observed-input standardization, P row-stochastic self-looped adjacency. For each class-pure group g, place seed columns for its indicator B_g and each dimension of B_g H. Apply the same truncated restart diffusion F_{0}=S, F_{t+1}=.15 S + .85 P F_t, T=8. This is a finite PPR approximation, computed on the graph and re-used for all query blocks. At a query, m_{qg}=F_{q,B_g}; local centroid is F_{q,B_g H}/m_{qg} when positive, else global group mean; the gate/fallback does not consult labels other than C. The group mean and total token member count are also supplied. This compresses additive PPR-weighted statistics exactly relative to this finite operator, not arbitrary posterior information, and is not teacher distillation. Query encoder compares H_q to local/global centroids by per-hop cosine and squared distances; pair channels include log1p-scaled mass and count and a reached flag. A shared pair MLP with two 48-unit hidden layers produces token score and head values. Per-class masked softmax over token scores uses a log-member-count weight, pools head values, then the same class scorer emits the logit for each class. Encode class identities only through grouping and shared readout. One forward per query block (arbitrary full query batch if it fits); no target optimizer step. Class-balanced query CE equally top-weights present classes during synthetic training; output is for this decision objective, not a proof of calibrated natural-population Bayes probability. No posterior teacher, extra loss, or pretrained checkpoint in the proposed small head.

## Controls, compute, data

- `tail` (proposed), `proportional` (same number of groups, minimum one per class, reserve remaining slots in proportion to observed counts subject to class capacity; same centroid/MLP), `top` (same per-class quotas as tail; keep individual context anchors with largest finite PPR for each query; observed count via total count/quota in token as the target group-size approximation, selection uses no query labels), `full` (all singleton anchors with identical decoder). All have their own matched initialization, task sequence and number of updates. Add balanced PPR class mean with uniform zero-mass fallback and label-aware nearest-centroid over H as no-training controls, and uniform-prior comparison. If usable locally, released NodePFN with no edits/no target updates as external descriptive comparison, not required for the bounded prototype. PCFI/GraphPFN missing baselines are for a subsequent missing-feature study; first pilot keeps observed features complete.
- For `top` avoid a dense N×N adjacency/PPR: diffuse a block of N×|C| singleton seeds; retrieve per class for each query. For compressed arms and full, permit block-wise group preprocessing and query scoring throughout. PPR computation is O(T E G(d+1)) in the compressed arm, memory O(N G(d+1)) if all seed columns retained. Neural stage O(QG) at fixed width, or O(BQ*G) pair activations when chunking query count BQ. Group partition, preprocessing, diffusion and neural forward all timed; do not claim O(1) at growing N or zero-shot no prior training. Same timing/device/threads/method warmup; separate preprocessing and scoring. Any large-graph (incl ogbn-arxiv) claim deferred until measured.
- Synthetic family: small degree-corrected SBM (bounded lognormal degree propensities, not an exact scale-free network), label population occupancy and independent observed support skew; graph-aware random nonlinear SCM features generated from exogenous noise/latent class vectors and graph propagation. Class names/roles randomized. Random module and episode seeds disjoint across splits. Train 320 groups per arm × 3 seeds; tasks N in {160,224,288}, K in {3,4,5}, feature width in {8,12,16}. Tail counts uniform1–4, head counts12–24, enforce minimum class/query support by construction and prevent any overlap. Include low/high edge label agreement and weak/strong feature mechanism. Entire class vocabulary observed. Random synthetic tasks are PFN prior episodes, not evidence of a novel generator relative to NodePFN/GraphPFN.
- Dev 12 graphs, independent from training. Final 96 independent synthetic graphs (48 matched, 48 larger N=512/640 with F=24 and larger head 24–40); balance graph and feature regime in each shape. Pair all arms on the same graph and label budget, queries class-stratified up to 8/class so tail recall is defined. Train from scratch on synthetic, evaluate final and real with frozen weights. Real development panel: immutable locally cached Cora/CiteSeer/PubMed (induced 2000), if raw features/labels are found; five random predetermined draws each with random observed tail (2 labels) vs head (choose 16 or smaller fixed limit based on source graph availability before scores); class-balanced query sampling unconstrained by target metrics; baseline gets same sets. Review reused real data descriptively, no between-graph generalization CI. Use native features projected label-free to a common width via deterministic random projection for all internal arms; do not equate with previously reported native NodePFN results. Exclude real evaluation only on documented availability, never performance.

## Predeclared decision

Primary tail bAcc = mean recall across classes with observed count≤4, seed means within each graph, paired 5,000 bootstrap of graph IDs within shape×graph regime×feature regime; two-sided nominal 97.5% intervals for primary contrasts. Go only if tail−proportional and tail−top lower>0, full guard tail−full lower>−2 pp overall balanced accuracy, and at least 2× smaller mean resident grouped context than full on scale holdout. Report overall/head bAcc, accuracy, NLL/Brier, budget/cost, rule controls, and application scope. If it loses to balanced PPR/centroid or incremental effect is absent, stop this pilot; no hyperparameter rescue on final. Sufficient evidence to scale further is stronger than passing unit tests. Same compression-shared decoder checks: graph-traversal dense oracle on tiny graph, sum/moment commutation, count/quotas, singleton parity, equal budget, class renaming and query chunk/permutation, impossible query-label leakage, zero PPR and differentiability at finite input. Recompute saved predictions' metrics from arrays. Source/config/split seeds locked before scientific runs.

Prior art: [NodePFN](https://arxiv.org/abs/2604.19028) and [GraphPFN](https://proceedings.mlr.press/v306/eremeev26a.html) already train on structured priors for graph ICL; [LoGIC](https://arxiv.org/html/2609.05955v1) already budgets labeled context and selects PPR/feature/coverage candidates; [Ephris](https://arxiv.org/html/2609.37057v1) already provides a scalable sparse ICL option; [Prototypical Networks](https://papers.neurips.cc/paper_files/paper/2017/hash/cb8da6767461f2812ae4290eac7cbc42-Abstract.html) uses learned prototype embeddings; [PPRGo](https://arxiv.org/abs/2007.01570) is prior PPR-based scalable GNN aggregation. We test observed-label-scarce allocation and finite-diffusion compression against matched alternatives.
