# SPFN01 — revised specification

Adopt PLAN_v1 except for the following fixed changes/clarifications. There are four synthetic-only trained arms: tail, proportional, top, full. Every method has access to the same G, X and observed (C,y_C); query labels are stored separately. This tests label scarcity, not feature missingness or complete topology replacement.

1. **Matched retrieval:** top selects raw singleton anchors by equal average within-class ranks of finite PPR and mean three-hop feature cosine, high scores first, ties by original context node ID. Use average ranks for score ties. Compute both scores for all context candidates, keep exactly the tail per-class quota, pass true per-anchor mass and member count 1, no rescaling fabricated support. All arms receive the original observed class count separately. The primary comparison is selection vs group aggregation with same token budget, not isolated effects of one scalar.
2. **Grouping/quota:** orient the within-class first PCA/SVD direction by the first max absolute projection in original-node-ID order, and use node ID to resolve near-degenerate gaps and ties. Within class split the ordered list into nearly equal buckets by `array_split`. Proportional quotas start from one slot per class and greedily allocate remaining slots to the largest current observed count per allocated slot among classes with spare capacity (ties by minimum context node ID of that class), until the exact tail total. Class IDs never break quotas/retrieval ties. Node reindexing with exact ties may change physical choices; report this limit.
3. **Diffusion:** P is the undirected simple adjacency with exactly one self-loop per node, normalized by row; isolated nodes have Pii=1. S-initialized 8-round finite restart is .15 Σ_{k=0}^{7}.85^k P^k + .85^8 P^8. Positive mass produces local centroid; zero mass uses global centroid, not a token mask. Use safe denominators and finite FP32. Only pooled groups need feature-weighted diffusion; full and top diffuse mass-only singleton seeds and gather H. Compressed arms likewise skip feature moments for singleton groups. Use sparse CSR and fixed group blocks; no N² adjacency in inference. Specs for width d use d=3F, PPR working storage depends on blocks and output query tensors; CPU diffusion may cost more than the optimized full arm. Log actual counts and timings; neither 2× context nor one forward per query block is a latency claim. Train one query batch/episode. Class balanced CE is a mean over nonempty query classes in the episode.
4. **Controls:** add an analytic ridge classifier over H with class-balanced weighted centering and fixed λ=.1, no gradient or target-validation step. Keep prior, PPR class-mean and nearest-centroid. This pilot uses no released PFN predictions: it isolates compression with shared train-from-scratch decoder; future external competition requires released NodePFN, GraphPFN, Ephris and same-budget LoGIC-style retrieval. Record exact baselines and scope.
5. **Protocol:** train fixed 320 independent prior episodes per seed using the same graph bank and seed-dependent common permutation. 320 optimizer steps ×3 seeds×4 arms, AdamW .001 wd .01, grad norm 1. Fixed final 2 shape×2 relation×2 feature regimes×12 graphs each. Record by construction all classes in C and Q (8 queries each, randomly drawn within class), use exactly ceil(K/2) tail classes, assign role independent of population after generating the graph. Dev 12 other graphs, touched only by numerical/smoke validation without model selection. Final larger graphs N512/640, F24, heads24–40 as in v1; keep both T8 and projection constant at inference. Label-state classes are permuted in synthetic generation. Synthetic assortativity regimes refer to the generator's bias, not a hard cut on observed graph metrics. No final evidence used for design.
6. **Real development:** reuse pinned Planetoid native cached Cora2708/CiteSeer3327/PubMed19717, verified official train/test disjoint. Full graph, deterministic graph-level label-free signed RP to 24 features before z-score, C chosen only from the official training split (all have20/class); 2 vs16 observations/class and ceil(K/2) random tail classes; all other official train labels are masked. Choose 32 queries/class from official test by fixed per-draw RNG. Five paired draws per graph. Use identical projected inputs for all; this is not a native-feature benchmark or an independent real holdout, nor is 16 vs 2 a severe large-class-budget claim. Ogbn-Arxiv is not evaluated. We report real stand-alone preprocessing timings but no dataset population CI.
7. **Gates:** nominal 97.5% 5,000 stratified paired-bootstrap intervals for tail bAcc on 96 fixed synthetic graphs, average three fixed seeds per graph; tail−proportional and tail−top lower>0 each. Overall bAcc tail−full lower>−2pp at same confidence. Scale-holdout ratio mean(full tokens)/mean(tail tokens)≥2 on 48 graphs. Tail mean synthetic tail bAcc must meet or exceed the maximum of all no-training rule-control point estimates (descriptive floor). All required for composite PASS. Policy preserves every ≤4 observed example; fine-tuning happens on the prior only, not real targets. Cost reporting includes all input conversion/graph processing and separately timed grouping, diffusion, scoring; log wall-time rather than infer robustness from it. Report repeatability, using same device/warmup and at least three repeats on one fixed real draw per graph for profile; report median and min/max.

External scope: no teacher/self-distillation in this MVP; “distillation” is structural compression of labeled evidence. Do not claim bounded total runtime in N, Bayes posterior recovery from a lossy summary, or novelty from SCM×SBM, PPR, or prototypes alone. Head/tail here refer to the number of observed labels. Graphs with zero examples of a class and novel class vocabulary are outside this test.
