## Candidate C: explicit finite centroid-grid model

For each class c,column f, mu_cf is a finite-grid latent variable with41 Gauss–Hermite locations transformed by a shared column center/scale, with normalized GH prior masses. Every class shares the same prior law. Observed-cell score is Normal(x_if;mu_s_i_f,sigma_f²). Product over class-gated pair factors gives this score exactly. **Exact summation in this finite grid is not exact integration of an arbitrary continuous centroid posterior.** Independent Gaussian noise across columns does not model RP-induced correlations.

Prior center starts at observed column mean. Class-balanced raw-family moment v_C=.36+.64/(C−1) gives initial tau0=sqrt((.64/(C−1))/v_C),sigma0=sqrt(.36/v_C). These are known-family moments, not realized true parameters and not an exact projected/clipped law. `C_global` has3 global raw coefficients, initially0. `C` predicts the same3 raw coefficients with a shared30→22→3 MLP using observed mean/std/RMS/count fraction,1/C,1/N and frozen observed-node structural representation24 pooled per column. Final layer zero-initialized so C/global initial hyperparameters match. Target751 parameters versus721 for A/B, actual counts reported. Location=observed_mean+std*tanh(raw0); each positive scale=.15+1.85*sigmoid(logit((base_scale−.15)/1.85)+raw_scale), so initial scales equal the moments and remain[.15,2]. No class IDs/free per-class learned parameters. Priors depend on visible input so this is a conditional structured score. Empty columns are inactive; query truth, true means/covariances and role never enter forward.

Use log-space class-gated sum-product messages with strict cavity exclusion. New factorization has length4 cycles for multiple sources; finite BP is an approximation. Do not reuse old Potts Bethe estimator for these feature factors. The common graph-only role protocol removes that confound. Source0 and singleton exchangeability imply graph-only prediction; verify the actual algorithm before any source0 cache shortcut.

## Outcomes / iteration

B-only improvement is interface-training evidence; C_global improvement is broader fixed-at-deployment centroid inference; C−C_global improvement is adaptive encoder evidence. Preserve each separately, never require C to win to acknowledge another valid effect. Check real feature utility and minority metrics, not only aggregate synthetic accuracy. If real utility is absent, do not declare the projection mismatch the unique cause or this cycle a missing-feature method success. Three reviewers inspect audited results. An implementation fault can trigger a documented repair; a changed scientific operator/prior starts FP02 with a new plan and new final specification, never a retune of FP01 final data.
